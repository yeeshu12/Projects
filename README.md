# Advanced URL Shortener

Features
- Shorten long URLs
- Redirect system
- Click analytics
- SQLite database

Run Backend
npm install express sqlite3 cors body-parser
node server.js

Run Frontend
create-react-app frontend
replace App.js with provided code
npm start
